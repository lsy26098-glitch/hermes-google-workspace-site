개인정보처리방침

시행일: 2026년 11월 7일

Hermes Google Workspace(이하 “서비스”)는 사용자가 소유하거나 관리하는 Google 계정과 개인용 Hermes Agent 환경을 연결하기 위한 비상업적 OAuth 통합입니다. 본 방침은 서비스가 Google 사용자 데이터를 어떻게 접근하고 처리하는지 설명합니다.

1. 접근하는 정보

사용자가 Google OAuth 화면에서 허용한 범위에 따라 다음 데이터에 접근할 수 있습니다.

  • Gmail: 이메일 조회, 전송 및 사용자가 요청한 메시지·라벨 처리
  • Google Calendar: 일정 조회 및 사용자가 승인한 일정 생성·수정·삭제
  • Google Drive: 파일과 폴더 조회 및 사용자가 승인한 업로드·다운로드·공유·삭제
  • Google Contacts: 연락처 조회
  • Google Sheets 및 Docs: 문서 조회 및 사용자가 승인한 생성·수정
  • OAuth 인증 정보: 액세스 토큰, 갱신 토큰 및 승인 범위

Google 계정 비밀번호는 수집하거나 저장하지 않습니다.

2. 이용 목적

Google 사용자 데이터는 사용자가 Hermes Agent에 명시적으로 요청한 작업을 수행하고, 인증 상태를 유지하며, 오류를 진단하는 목적으로만 사용합니다.

3. 데이터 저장과 보관

OAuth 토큰은 사용자의 Hermes Agent 실행 환경에 로컬로 저장됩니다. 서비스 운영자는 별도의 원격 사용자 데이터베이스를 운영하지 않습니다. 사용자가 생성하거나 내려받은 결과물은 사용자가 지정한 로컬 위치 또는 사용자의 Google 계정에 저장됩니다.

4. 데이터 공유

Google 사용자 데이터를 판매하지 않으며, 광고 목적으로 사용하지 않습니다. 사용자가 특정 파일 공유, 이메일 발송 또는 일정 초대를 명시적으로 요청한 경우를 제외하고 제3자에게 데이터를 제공하지 않습니다. 법률상 의무가 있는 경우에는 요구되는 범위에서만 처리할 수 있습니다.

5. 사용자 통제와 삭제

사용자는 Google 계정의 보안 설정에서 언제든지 서비스 접근 권한을 취소할 수 있습니다. 로컬 Hermes Agent 환경의 OAuth 토큰 파일을 삭제하거나 연결 해제 기능을 실행하여 저장된 인증 정보를 제거할 수도 있습니다.

6. 보안

서비스는 OAuth 2.0을 사용하며, 가능한 범위에서 최소 권한과 사용자 확인 절차를 적용합니다. 다만 인터넷 전송 또는 전자 저장 방식의 완전한 보안을 보장할 수는 없습니다.

7. Google API 서비스 사용자 데이터 정책

본 서비스의 Google API를 통한 정보 이용은 제한적 사용 요건을 포함한 Google API Services User Data Policy를 준수합니다.

8. 방침 변경

서비스 기능이나 법적 요구사항이 변경되면 본 방침을 수정할 수 있습니다. 중요한 변경은 이 페이지의 시행일을 갱신하여 알립니다.
