1. 서비스 목적

Hermes Google Workspace는 사용자가 개인용 Hermes Agent 환경에서 자신의 Google Workspace 데이터에 접근하고 요청한 작업을 수행하도록 돕는 비상업적 통합입니다.

2. 사용자 책임

  • 사용자는 자신이 접근 권한을 가진 Google 계정과 데이터에 대해서만 서비스를 사용해야 합니다.
  • 이메일 발송, 파일 공유·삭제, 일정 변경 등 외부 영향을 주는 작업은 실행 전에 내용을 확인해야 합니다.
  • OAuth 자격증명과 로컬 토큰을 안전하게 관리해야 합니다.

3. 금지되는 사용

불법 행위, 무단 접근, 스팸 발송, 타인의 개인정보 침해, Google 또는 제3자의 서비스 약관을 위반하는 목적으로 서비스를 사용할 수 없습니다.

4. 가용성과 보증

서비스는 현재 상태로 제공되며, 중단 없는 작동이나 특정 목적 적합성을 보증하지 않습니다. Google API 정책, 계정 권한 또는 네트워크 상태에 따라 기능이 제한될 수 있습니다.

5. 책임 제한

관련 법률이 허용하는 범위에서 서비스 사용 또는 사용 불가로 발생한 간접적·부수적 손해에 대한 책임을 제한합니다. 중요한 변경 작업 전에는 사용자가 대상과 내용을 확인해야 합니다.

6. 접근 철회

사용자는 언제든지 Google 계정 보안 설정에서 OAuth 접근 권한을 철회하고 로컬 인증 정보를 삭제하여 서비스 이용을 종료할 수 있습니다.
